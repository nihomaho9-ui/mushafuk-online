تيسير الكريم الرحمن — السعدي

فَأَهْلَكْنَآ أَشَدَّ مِنْهُم بَطْشًا وَمَضَىٰ مَثَلُ ٱلْأَوَّلِينَ ﴿٨﴾

{ فَأَهْلَكْنَا أَشَدّ } من هؤلاء { بَطْشًا } أي: قوة وأفعالا وآثارا في الأرض، { وَمَضَى مَثَلُ الْأَوَّلِينَ } أي: مضت أمثالهم وأخبارهم، وبينا لكم منها ما فيه عبرة ومزدجر عن التكذيب والإنكار.
