تيسير الكريم الرحمن — السعدي

فَٱنتَقَمْنَا مِنْهُمْ ۖ فَٱنظُرْ كَيْفَ كَانَ عَـٰقِبَةُ ٱلْمُكَذِّبِينَ ﴿٢٥﴾

{ فَانْتَقَمْنَا مِنْهُمْ } بتكذيبهم الحق، وردهم إياه بهذه الشبهة الباطلة. { فَانْظُرْ كَيْفَ كَانَ عَاقِبَةُ الْمُكَذِّبِينَ } فليحذر هؤلاء أن يستمروا على تكذيبهم، فيصيبهم ما أصابهم.
