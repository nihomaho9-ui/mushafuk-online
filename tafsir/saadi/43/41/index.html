تيسير الكريم الرحمن — السعدي

فَإِمَّا نَذْهَبَنَّ بِكَ فَإِنَّا مِنْهُم مُّنتَقِمُونَ ﴿٤١﴾

{ أَوْ نُرِيَنَّكَ الَّذِي وَعَدْنَاهُمْ } من العذاب { فَإِنَّا عَلَيْهِمْ مُقْتَدِرُونَ } ولكن ذلك متوقف على اقتضاء الحكمة لتعجيله أو تأخيره، فهذه حالك وحال هؤلاء المكذبين.
