تيسير الكريم الرحمن — السعدي

ثُمَّ إِنَّكُمْ يَوْمَ ٱلْقِيَـٰمَةِ عِندَ رَبِّكُمْ تَخْتَصِمُونَ ﴿٣١﴾

{ ثُمَّ إِنَّكُمْ يَوْمَ الْقِيَامَةِ عِنْدَ رَبِّكُمْ تَخْتَصِمُونَ } فيما تنازعتم فيه، فيفصل بينكم بحكمه العادل، ويجازي كُلًّا ما عمله { أَحْصَاهُ اللَّهُ وَنَسُوهُ }
