تيسير الكريم الرحمن — السعدي

وَأَنَّا لَمَسْنَا ٱلسَّمَآءَ فَوَجَدْنَـٰهَا مُلِئَتْ حَرَسًا شَدِيدًا وَشُهُبًا ﴿٨﴾

{ وَأَنَّا لَمَسْنَا السَّمَاءَ } أي: أتيناها واختبرناها، { فَوَجَدْنَاهَا مُلِئَتْ حَرَسًا شَدِيدًا } عن الوصول إلى أرجائها [والدنو منها]، { وَشُهُبًا } يرمى بها من استرق السمع، وهذا بخلاف عادتنا الأولى، فإنا كنا نتمكن من الوصول إلى خبر السماء.
