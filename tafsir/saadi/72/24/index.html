الجنالآية ٢٤

تيسير الكريم الرحمن — السعدي

حَتَّىٰٓ إِذَا رَأَوْا۟ مَا يُوعَدُونَ فَسَيَعْلَمُونَ مَنْ أَضْعَفُ نَاصِرًا وَأَقَلُّ عَدَدًا ﴿٢٤﴾

{ حَتَّى إِذَا رَأَوْا مَا يُوعَدُونَ } أي: شاهدوه عيانا، وجزموا أنه واقع بهم، { فَسَيَعْلَمُونَ } في ذلك الوقت حقيقة المعرفة { مَنْ أَضْعَفُ نَاصِرًا وَأَقَلُّ عَدَدًا } حين لا ينصرهم غيرهم ولا أنفسهم ينتصرون، وإذ يحشرون فرادى كما خلقوا أول مرة.
