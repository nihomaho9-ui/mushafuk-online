تيسير الكريم الرحمن — السعدي

ثُمَّ ٱرْجِعِ ٱلْبَصَرَ كَرَّتَيْنِ يَنقَلِبْ إِلَيْكَ ٱلْبَصَرُ خَاسِئًا وَهُوَ حَسِيرٌ ﴿٤﴾

{ ثُمَّ ارْجِعِ الْبَصَرَ كَرَّتَيْنِ } المراد بذلك: كثرة التكرار { يَنْقَلِبْ إِلَيْكَ الْبَصَرُ خَاسِئًا وَهُوَ حَسِيرٌ } أي: عاجزًا عن أن يرى خللًا أو فطورًا، ولو حرص غاية الحرص. ثم صرح بذكر حسنها فقال:
