هودالآية ٧٥

تيسير الكريم الرحمن — السعدي

إِنَّ إِبْرَٰهِيمَ لَحَلِيمٌ أَوَّٰهٌ مُّنِيبٌ ﴿٧٥﴾

{ إِنَّ إِبْرَاهِيمَ لَحَلِيمٌ } أي: ذو خلق حسن وسعة صدر، وعدم غضب، عند جهل الجاهلين. { أَوَّاهٌ } أي: متضرع إلى الله في جميع الأوقات، { مُنِيبٌ } أي: رجَّاع إلى الله بمعرفته ومحبته، والإقبال عليه, والإعراض عمن سواه، فلذلك كان يجادل عمن حتَّم الله بهلاكهم.
