تيسير الكريم الرحمن — السعدي

وَيَصْنَعُ ٱلْفُلْكَ وَكُلَّمَا مَرَّ عَلَيْهِ مَلَأٌ مِّن قَوْمِهِۦ سَخِرُوا۟ مِنْهُ ۚ قَالَ إِن تَسْخَرُوا۟ مِنَّا فَإِنَّا نَسْخَرُ مِنكُمْ كَمَا تَسْخَرُونَ ﴿٣٨﴾

ـفامتثل أمر ربه، وجعل يصنع الفلك { وَكُلَّمَا مَرَّ عَلَيْهِ مَلَأٌ مِنْ قَوْمِهِ } ورأوا ما يصنع { سَخِرُوا مِنْهُ قَالَ إِنْ تَسْخَرُوا مِنَّا } الآن { فَإِنَّا نَسْخَرُ مِنْكُمْ كَمَا تَسْخَرُونَ *} .
