هودالآية ٨٣

تيسير الكريم الرحمن — السعدي

مُّسَوَّمَةً عِندَ رَبِّكَ ۖ وَمَا هِىَ مِنَ ٱلظَّـٰلِمِينَ بِبَعِيدٍ ﴿٨٣﴾

{ مُسَوَّمَةً عِنْدَ رَبِّكَ } أي: معلمة، عليها علامة العذاب والغضب، { وَمَا هِيَ مِنَ الظَّالِمِينَ } الذين يشابهون لفعل قوم لوط { بِبَعِيدٍ } فليحذر العباد، أن يفعلوا كفعلهم، لئلا يصيبهم ما أصابهم.
