تيسير الكريم الرحمن — السعدي

وَٱمْرَأَتُهُۥ قَآئِمَةٌ فَضَحِكَتْ فَبَشَّرْنَـٰهَا بِإِسْحَـٰقَ وَمِن وَرَآءِ إِسْحَـٰقَ يَعْقُوبَ ﴿٧١﴾

وامرأة إبراهيم { قَائِمَةٌ } تخدم أضيافه { فَضَحِكَتْ } حين سمعت بحالهم، وما أرسلوا به، تعجبا. { فَبَشَّرْنَاهَا بِإِسْحَاقَ وَمِنْ وَرَاءِ إِسْحَاقَ يَعْقُوبَ } فتعجبت من ذلك.
