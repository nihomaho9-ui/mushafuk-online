تيسير الكريم الرحمن — السعدي

لَا جَرَمَ أَنَّهُمْ فِى ٱلْـَٔاخِرَةِ هُمُ ٱلْأَخْسَرُونَ ﴿٢٢﴾

{ لَا جَرَمَ } أي: حقا وصدقا { أَنَّهُمْ فِي الْآخِرَةِ هُمُ الْأَخْسَرُونَ } حصر الخسار فيهم، بل جعل لهم منه أشده، لشدة حسرتهم وحرمانهم وما يعانون من المشقة والعذاب، نستجير بالله من حالهم.
