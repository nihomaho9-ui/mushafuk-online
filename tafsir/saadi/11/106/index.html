هودالآية ١٠٦

تيسير الكريم الرحمن — السعدي

فَأَمَّا ٱلَّذِينَ شَقُوا۟ فَفِى ٱلنَّارِ لَهُمْ فِيهَا زَفِيرٌ وَشَهِيقٌ ﴿١٠٦﴾

وأما جزاؤهم { فَأَمَّا الَّذِينَ شَقُوا ْ} أي: حصلت لهم الشقاوة، والخزي والفضيحة، { فَفِي النَّارِ ْ} منغمسون في عذابها، مشتد عليهم عقابها، { لَهُمْ فِيهَا ْ} من شدة ما هم فيه { زَفِيرٌ وَشَهِيقٌ ْ} وهو أشنع الأصوات وأقبحها.
