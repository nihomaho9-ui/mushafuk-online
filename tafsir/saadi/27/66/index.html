تيسير الكريم الرحمن — السعدي

بَلِ ٱدَّٰرَكَ عِلْمُهُمْ فِى ٱلْـَٔاخِرَةِ ۚ بَلْ هُمْ فِى شَكٍّ مِّنْهَا ۖ بَلْ هُم مِّنْهَا عَمُونَ ﴿٦٦﴾

{ بَلِ ادَّارَكَ عِلْمُهُمْ فِي الْآخِرَةِ } أي: بل ضعف، وقل ولم يكن يقينا، ولا علما واصلا إلى القلب وهذا أقل وأدنى درجة للعلم ضعفه ووهاؤه، بل ليس عندهم علم قوي ولا ضعيف وإنما { هُمْ فِي شَكٍّ مِنْهَا } أي: من الآخرة، والشك زال به العلم لأن العلم بجميع مراتبه لا يجامع الشك، { بَلْ هُمْ مِنْهَا } أي: من الآخرة { عَمُونَ } قد عميت عنها بصائرهم، ولم يكن في قلوبهم من وقوعها ولا احتمال بل أنكروها واستبعدوها.
