تيسير الكريم الرحمن — السعدي

وَٱلَّذِينَ هُم بِشَهَـٰدَٰتِهِمْ قَآئِمُونَ ﴿٣٣﴾

{ وَالَّذِينَ هُمْ بِشَهَادَاتِهِمْ قَائِمُونَ } أي: لا يشهدون إلا بما يعلمونه، من غير زيادة ولا نقص ولا كتمان، ولا يحابي فيها قريبا ولا صديقا ونحوه، ويكون القصد بها وجه الله. قال تعالى: { وَأَقِيمُوا الشَّهَادَةَ لِلَّهِ } { يَا أَيُّهَا الَّذِينَ آمَنُوا كُونُوا قَوَّامِينَ بِالْقِسْطِ شُهَدَاءَ لِلَّهِ وَلَوْ عَلَى أَنْفُسِكُمْ أَوِ الْوَالِدَيْنِ وَالْأَقْرَبِينَ } .
