النساءالآية ١٠٦

تيسير الكريم الرحمن — السعدي

وَٱسْتَغْفِرِ ٱللَّهَ ۖ إِنَّ ٱللَّهَ كَانَ غَفُورًا رَّحِيمًا ﴿١٠٦﴾

{ وَاسْتَغْفِرِ اللَّهَ } مما صدر منك إن صدر. { إِنَّ اللَّهَ كَانَ غَفُورًا رَحِيمًا } أي: يغفر الذنب العظيم لمن استغفره، وتاب إليه وأناب ويوفقه للعمل الصالح بعد ذلك الموجِب لثوابه وزوال عقابه.
