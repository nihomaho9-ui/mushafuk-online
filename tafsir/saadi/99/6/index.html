تيسير الكريم الرحمن — السعدي

يَوْمَئِذٍ يَصْدُرُ ٱلنَّاسُ أَشْتَاتًا لِّيُرَوْا۟ أَعْمَـٰلَهُمْ ﴿٦﴾

{ يَوْمَئِذٍ يَصْدُرُ النَّاسُ } من موقف القيامة، حين يقضي الله بينهم { أَشْتَاتًا } أي: فرقًا متفاوتين. { لِيُرَوْا أَعْمَالَهُمْ } أي: ليريهم الله ما عملوا من الحسنات والسيئات، ويريهم جزاءه موفرًا.
