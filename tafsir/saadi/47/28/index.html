تيسير الكريم الرحمن — السعدي

ذَٰلِكَ بِأَنَّهُمُ ٱتَّبَعُوا۟ مَآ أَسْخَطَ ٱللَّهَ وَكَرِهُوا۟ رِضْوَٰنَهُۥ فَأَحْبَطَ أَعْمَـٰلَهُمْ ﴿٢٨﴾

{ ذَلِكَ } العذاب الذي استحقوه ونالوه { بـ } سبب { أنهم اتَّبَعُوا مَا أَسْخَطَ اللَّهَ } من كل كفر وفسوق وعصيان.{ وَكَرِهُوا رِضْوَانَهُ } فلم يكن لهم رغبة فيما يقربهم إليه، ولا يدنيهم منه، { فَأَحْبَطَ أَعْمَالَهُمْ } أي: أبطلها وأذهبها، وهذا بخلاف من اتبع ما يرضي الله وكره سخطه، فإنه سيكفر عنه سيئاته، ويضاعف أجره وثوابه.
