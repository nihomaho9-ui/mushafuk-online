تيسير الكريم الرحمن — السعدي

فَكَيْفَ إِذَا تَوَفَّتْهُمُ ٱلْمَلَـٰٓئِكَةُ يَضْرِبُونَ وُجُوهَهُمْ وَأَدْبَـٰرَهُمْ ﴿٢٧﴾

{ فَكَيْفَ } ترى حالهم الشنيعة، ورؤيتهم الفظيعة { إِذَا تَوَفَّتْهُمُ الْمَلَائِكَة } الموكلون بقبض أرواحهم، { يَضْرِبُونَ وُجُوهَهُمْ وَأَدْبَارَهُمْ } بالمقامع الشديدة؟!.
