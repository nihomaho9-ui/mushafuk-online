محمدالآية ٢٣

تيسير الكريم الرحمن — السعدي

أُو۟لَـٰٓئِكَ ٱلَّذِينَ لَعَنَهُمُ ٱللَّهُ فَأَصَمَّهُمْ وَأَعْمَىٰٓ أَبْصَـٰرَهُمْ ﴿٢٣﴾

{ أُولَئِكَ الَّذِينَ } أفسدوا في الأرض، وقطعوا أرحامهم { لَعَنَهُمُ اللَّهُ } بأن أبعدهم عن رحمته، وقربوا من سخط الله.{ فَأَصَمَّهُمْ وَأَعْمَى أَبْصَارَهُمْ } أي: جعلهم لا يسمعون ما ينفعهم ولا يبصرونه، فلهم آذان، ولكن لا تسمع سماع إذعان وقبول، وإنما تسمع سماعا تقوم به حجة الله عليها، ولهم أعين، ولكن لا يبصرون بها العبر والآيات، ولا يلتفتون بها إلى البراهين والبينات.
