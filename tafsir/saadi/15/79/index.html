الحجرالآية ٧٩

تيسير الكريم الرحمن — السعدي

فَٱنتَقَمْنَا مِنْهُمْ وَإِنَّهُمَا لَبِإِمَامٍ مُّبِينٍ ﴿٧٩﴾

{ فَانْتَقَمْنَا مِنْهُمْ } فأخذهم عذاب يوم الظلة إنه كان عذاب يوم عظيم. { وَإِنَّهُمَا } أي: ديار قوم لوط وأصحاب الأيكة { لَبِإِمَامٍ مُبِينٍ } أي: لبطريق واضح يمر بهم المسافرون كل وقت، فيبين من آثارهم ما هو مشاهد بالأبصار فيعتبر بذلك أولوا الألباب.
