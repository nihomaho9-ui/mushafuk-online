تيسير الكريم الرحمن — السعدي

صُمٌّۢ بُكْمٌ عُمْىٌ فَهُمْ لَا يَرْجِعُونَ ﴿١٨﴾

{ صُمٌّ } أي: عن سماع الخير، { بُكْمٌ } [أي]: عن النطق به، { عُمْيٌ } عن رؤية الحق، { فَهُمْ لَا يَرْجِعُونَ } لأنهم تركوا الحق بعد أن عرفوه, فلا يرجعون إليه، بخلاف من ترك الحق عن جهل وضلال, فإنه لا يعقل, وهو أقرب رجوعا منهم.
