تيسير الكريم الرحمن — السعدي

وَلَقَدْ جَآءَكُم مُّوسَىٰ بِٱلْبَيِّنَـٰتِ ثُمَّ ٱتَّخَذْتُمُ ٱلْعِجْلَ مِنۢ بَعْدِهِۦ وَأَنتُمْ ظَـٰلِمُونَ ﴿٩٢﴾

{ وَلَقَدْ جَاءَكُمْ مُوسَى بِالْبَيِّنَاتِ } أي: بالأدلة الواضحات المبينة للحق، { ثُمَّ اتَّخَذْتُمُ الْعِجْلَ مِنْ بَعْدِهِ } أي: بعد مجيئه { وَأَنْتُمْ ظَالِمُونَ } في ذلك ليس لكم عذر.
