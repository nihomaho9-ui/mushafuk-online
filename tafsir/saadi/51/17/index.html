تيسير الكريم الرحمن — السعدي

كَانُوا۟ قَلِيلًا مِّنَ ٱلَّيْلِ مَا يَهْجَعُونَ ﴿١٧﴾

{ كَانُوا } أي: المحسنون { قَلِيلًا مِنَ اللَّيْلِ مَا يَهْجَعُونَ } أي: كان هجوعهم أي: نومهم بالليل، قليلاً، وأما أكثر الليل، فإنهم قانتون لربهم، ما بين صلاة، وقراءة، وذكر، ودعاء، وتضرع.
