النحلالآية ٦١

تيسير الكريم الرحمن — السعدي

وَلَوْ يُؤَاخِذُ ٱللَّهُ ٱلنَّاسَ بِظُلْمِهِم مَّا تَرَكَ عَلَيْهَا مِن دَآبَّةٍ وَلَـٰكِن يُؤَخِّرُهُمْ إِلَىٰٓ أَجَلٍ مُّسَمًّى ۖ فَإِذَا جَآءَ أَجَلُهُمْ لَا يَسْتَـْٔخِرُونَ سَاعَةً ۖ وَلَا يَسْتَقْدِمُونَ ﴿٦١﴾

لما ذكر تعالى ما افتراه الظالمون عليه ذكر كمال حلمه وصبره فقال: { وَلَوْ يُؤَاخِذُ اللَّهُ النَّاسَ بِظُلْمِهِمْ } من غير زيادة ولا نقص، { مَا تَرَكَ عَليها مِنْ دَابَّةٍ } أي: لأهلك المباشرين للمعصية وغيرهم، من أنواع الدواب والحيوانات فإن شؤم المعاصي يهلك به الحرث والنسل. { وَلَكِنْ يُؤَخِّرُهُمْ } عن تعجيل العقوبة عليهم إلى أجل مسمى وهو يوم القيامة { فَإِذَا جَاءَ أَجَلُهُمْ لَا يَسْتَأْخِرُونَ سَاعَةً وَلَا يَسْتَقْدِمُونَ } فليحذروا ما داموا في وقت الإمهال قبل أن يجيء الوقت الذي لا إمهال فيه.
