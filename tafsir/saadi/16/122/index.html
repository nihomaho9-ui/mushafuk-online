النحلالآية ١٢٢

تيسير الكريم الرحمن — السعدي

وَءَاتَيْنَـٰهُ فِى ٱلدُّنْيَا حَسَنَةً ۖ وَإِنَّهُۥ فِى ٱلْـَٔاخِرَةِ لَمِنَ ٱلصَّـٰلِحِينَ ﴿١٢٢﴾

{ وَآتَيْنَاهُ فِي الدُّنْيَا حَسَنَةً } رزقا واسعا، وزوجة حسناء، وذرية صالحين، وأخلاقا مرضية { وَإِنَّهُ فِي الْآخِرَةِ لَمِنَ الصَّالِحِينَ } الذين لهم المنازل العالية والقرب العظيم من الله تعالى.
