النحلالآية ١١٥

تيسير الكريم الرحمن — السعدي

إِنَّمَا حَرَّمَ عَلَيْكُمُ ٱلْمَيْتَةَ وَٱلدَّمَ وَلَحْمَ ٱلْخِنزِيرِ وَمَآ أُهِلَّ لِغَيْرِ ٱللَّهِ بِهِۦ ۖ فَمَنِ ٱضْطُرَّ غَيْرَ بَاغٍ وَلَا عَادٍ فَإِنَّ ٱللَّهَ غَفُورٌ رَّحِيمٌ ﴿١١٥﴾

{ إِنَّمَا حَرَّمَ عَلَيْكُمُ } الأشياء المضرة تنزيها لكم، وذلك: كـ { الْمَيْتَةَ } ويدخل في ذلك كل ما كان موته على غير ذكاة مشروعة، ويستثنى من ذلك ميتة الجراد والسمك. { والدم } المسفوح وأما ما يبقى في العروق واللحم فلا يضر. { وَلَحْمَ الْخِنْزِيرِ } لقذارته وخبثه وذلك شامل للحمه وشحمه وجميع أجزائه. { وَمَا أُهِلَّ لِغَيْرِ اللَّهِ بِهِ } كالذي يذبح للأصنام والقبور ونحوها لأنه مقصود به الشرك. { فَمَنِ اضْطُرَّ } إلى شيء من المحرمات -بأن حملته الضرورة وخاف إن لم يأكل أن يهلك- فلا جناح عليه إذا لم يكن باغيا أو عاديا، أي: إذا لم يرد أكل المحرم وهو غير مضطر، ولا متعد الحلال إلى الحرام، أو متجاوز لما زاد على قدر الضرورة، فهذا الذي حرمه الله من المباحات.
