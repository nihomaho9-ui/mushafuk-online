النحلالآية ١٢٠

تيسير الكريم الرحمن — السعدي

إِنَّ إِبْرَٰهِيمَ كَانَ أُمَّةً قَانِتًا لِّلَّهِ حَنِيفًا وَلَمْ يَكُ مِنَ ٱلْمُشْرِكِينَ ﴿١٢٠﴾

يخبر تعالى عما فضل به خليله إبراهيم عليه الصلاة والسلام، وخصه به من الفضائل العالية والمناقب الكاملة فقال: { إِنَّ إِبْرَاهِيمَ كَانَ أُمَّةً } أي: إماما جامعا لخصال الخير هاديا مهتديا. { قَانِتًا لِلَّهِ } أي: مديما لطاعة ربه مخلصا له الدين، { حَنِيفًا } مقبلا على الله بالمحبة، والإنابة والعبودية معرضا عمن سواه. { وَلَمْ يَكُ مِنَ الْمُشْرِكِينَ } في قوله وعمله، وجميع أحواله لأنه إمام الموحدين الحنفاء.
