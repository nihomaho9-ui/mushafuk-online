الآية ٤٤

تيسير الكريم الرحمن — السعدي

يَوْمَ تَشَقَّقُ ٱلْأَرْضُ عَنْهُمْ سِرَاعًا ۚ ذَٰلِكَ حَشْرٌ عَلَيْنَا يَسِيرٌ ﴿٤٤﴾

{ يَوْمَ تَشَقَّقُ الْأَرْضُ عَنْهُمْ } أي: عن الأموات { سِرَاعًا } أي: يسرعون لإجابة الداعي لهم، إلى موقف القيامة، { ذَلِكَ حَشْرٌ عَلَيْنَا يَسِيرٌ } أي: هين على الله يسير لا تعب فيه ولا كلفة.
