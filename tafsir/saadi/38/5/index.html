صالآية ٥

تيسير الكريم الرحمن — السعدي

أَجَعَلَ ٱلْـَٔالِهَةَ إِلَـٰهًا وَٰحِدًا ۖ إِنَّ هَـٰذَا لَشَىْءٌ عُجَابٌ ﴿٥﴾

وذنبه -عندهم- أنه { أَجَعَلَ الْآلِهَةَ إِلَهًا وَاحِدًا } أى: كيف ينهى عن اتخاذ الشركاء والأنداد، ويأمر بإخلاص العبادة للّه وحده. { إِنَّ هَذَا } الذي جاء به { لَشَيْءٌ عُجَابٌ } أي: يقضي منه العجب لبطلانه وفساده.
