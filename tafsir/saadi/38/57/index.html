صالآية ٥٧

تيسير الكريم الرحمن — السعدي

هَـٰذَا فَلْيَذُوقُوهُ حَمِيمٌ وَغَسَّاقٌ ﴿٥٧﴾

{ هَذَا } المهاد، هذا العذاب الشديد، والخزي والفضيحة والنكال { فَلْيَذُوقُوهُ حَمِيمٌ } ماء حار، قد اشتد حره، يشربونه فَيقَطعُ أمعاءهم. { وَغَسَّاقٌ } وهو أكره ما يكون من الشراب، من قيح وصديد، مر المذاق، كريه الرائحة.
