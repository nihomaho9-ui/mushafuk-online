تيسير الكريم الرحمن — السعدي

وَأَنزَلَ ٱلَّذِينَ ظَـٰهَرُوهُم مِّنْ أَهْلِ ٱلْكِتَـٰبِ مِن صَيَاصِيهِمْ وَقَذَفَ فِى قُلُوبِهِمُ ٱلرُّعْبَ فَرِيقًا تَقْتُلُونَ وَتَأْسِرُونَ فَرِيقًا ﴿٢٦﴾

{ وَأَنْزَلَ الَّذِينَ ظَاهَرُوهُمْ } أي عاونوهم { مِنْ أَهْلِ الْكِتَابِ } أي: اليهود { مِنْ صَيَاصِيهِمْ } أي: أنزلهم من حصونهم، نزولاً مظفورًا بهم، مجعولين تحت حكم الإسلام.{ وَقَذَفَ فِي قُلُوبِهِمُ الرُّعْبَ } فلم يقووا على القتال، بل استسلموا وخضعوا وذلوا. { فَرِيقًا تَقْتُلُونَ } وهم الرجال المقاتلون { وَتَأْسِرُونَ فَرِيقًا } مَنْ عداهم من النساء والصبيان.
