تيسير الكريم الرحمن — السعدي

إِن تُبْدُوا۟ شَيْـًٔا أَوْ تُخْفُوهُ فَإِنَّ ٱللَّهَ كَانَ بِكُلِّ شَىْءٍ عَلِيمًا ﴿٥٤﴾

ثم قال تعالى: { إِنْ تُبْدُوا شَيْئًا } أي تظهروه { أَوْ تُخْفُوهُ فَإِنَّ اللَّهَ كَانَ بِكُلِّ شَيْءٍ عَلِيمًا } يعلم ما في قلوبكم، وما أظهرتموه، فيجازيكم عليه.
