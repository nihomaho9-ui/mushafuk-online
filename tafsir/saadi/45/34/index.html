تيسير الكريم الرحمن — السعدي

وَقِيلَ ٱلْيَوْمَ نَنسَىٰكُمْ كَمَا نَسِيتُمْ لِقَآءَ يَوْمِكُمْ هَـٰذَا وَمَأْوَىٰكُمُ ٱلنَّارُ وَمَا لَكُم مِّن نَّـٰصِرِينَ ﴿٣٤﴾

{ وَقِيلَ الْيَوْمَ نَنْسَاكُمْ } أي: نترككم في العذاب { كَمَا نَسِيتُمْ لِقَاءَ يَوْمِكُمْ هَذَا } فإن الجزاء من جنس العمل { وَمَأْوَاكُمُ النَّارُ } أي: هي مقركم ومصيركم، { وَمَا لَكُمْ مِنْ نَاصِرِينَ } ينصرونكم من عذاب الله ويدفعون عنكم عقابه.
