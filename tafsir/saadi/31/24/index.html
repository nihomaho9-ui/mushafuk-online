لقمانالآية ٢٤

تيسير الكريم الرحمن — السعدي

نُمَتِّعُهُمْ قَلِيلًا ثُمَّ نَضْطَرُّهُمْ إِلَىٰ عَذَابٍ غَلِيظٍ ﴿٢٤﴾

{ نُمَتِّعُهُمْ قَلِيلًا } في الدنيا، ليزداد إثمهم، ويتوفر عذابهم، { ثُمَّ نَضْطَرُّهُمْ } أي: [نلجئهم] { إِلَى عَذَابٍ غَلِيظٍ } أي: انتهى في عظمه وكبره، وفظاعته، وألمه، وشدته.
