غافرالآية ٧٦

تيسير الكريم الرحمن — السعدي

ٱدْخُلُوٓا۟ أَبْوَٰبَ جَهَنَّمَ خَـٰلِدِينَ فِيهَا ۖ فَبِئْسَ مَثْوَى ٱلْمُتَكَبِّرِينَ ﴿٧٦﴾

{ ادْخُلُوا أَبْوَابَ جَهَنَّمَ } كل بطبقة من طبقاتها، على قدر عمله. { خَالِدِينَ فِيهَا } لا يخرجون منها أبدًا { فَبِئْسَ مَثْوَى الْمُتَكَبِّرِينَ } مثوى يخزون فيه، ويهانون، ويحبسون، ويعذبون، ويترددون بين حرها وزمهريرها.
