تيسير الكريم الرحمن — السعدي

يَوْمَ لَا يَنفَعُ ٱلظَّـٰلِمِينَ مَعْذِرَتُهُمْ ۖ وَلَهُمُ ٱللَّعْنَةُ وَلَهُمْ سُوٓءُ ٱلدَّارِ ﴿٥٢﴾

{ يَوْمَ لَا يَنْفَعُ الظَّالِمِينَ مَعْذِرَتُهُمْ } حين يعتذرون { وَلَهُمُ اللَّعْنَةُ وَلَهُمْ سُوءُ الدَّارِ } أي: الدار السيئة التي تسوء نازليها.
