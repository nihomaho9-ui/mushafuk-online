غافرالآية ٤٩

تيسير الكريم الرحمن — السعدي

وَقَالَ ٱلَّذِينَ فِى ٱلنَّارِ لِخَزَنَةِ جَهَنَّمَ ٱدْعُوا۟ رَبَّكُمْ يُخَفِّفْ عَنَّا يَوْمًا مِّنَ ٱلْعَذَابِ ﴿٤٩﴾

{ وَقَالَ الَّذِينَ فِي النَّارِ } من المستكبرين والضعفاء { لِخَزَنَةِ جَهَنَّمَ ادْعُوا رَبَّكُمْ يُخَفِّفْ عَنَّا يَوْمًا مِنَ الْعَذَابِ } لعله تحصل بعض الراحة.
