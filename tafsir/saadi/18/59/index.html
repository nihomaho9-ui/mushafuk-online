الكهفالآية ٥٩

تيسير الكريم الرحمن — السعدي

وَتِلْكَ ٱلْقُرَىٰٓ أَهْلَكْنَـٰهُمْ لَمَّا ظَلَمُوا۟ وَجَعَلْنَا لِمَهْلِكِهِم مَّوْعِدًا ﴿٥٩﴾

{ وَتِلْكَ الْقُرَى أَهْلَكْنَاهُمْ لَمَّا ظَلَمُوا } أي: بظلمهم، لا بظلم منا { وَجَعَلْنَا لِمَهْلِكِهِمْ مَوْعِدًا } أي: وقتا مقدرا، لا يتقدمون عنه ولا يتأخرون.
