تيسير الكريم الرحمن — السعدي

فَٱسْتَجَبْنَا لَهُۥ وَنَجَّيْنَـٰهُ مِنَ ٱلْغَمِّ ۚ وَكَذَٰلِكَ نُـۨجِى ٱلْمُؤْمِنِينَ ﴿٨٨﴾

: { فَاسْتَجَبْنَا لَهُ وَنَجَّيْنَاهُ مِنَ الْغَمِّ } أي: الشدة التي وقع فيها. { وَكَذَلِكَ نُنْجِي الْمُؤْمِنِينَ } وهذا وعد وبشارة، لكل مؤمن وقع في شدة وغم، أن الله تعالى سينجيه منها، ويكشف عنه ويخفف، لإيمانه كما فعل بـ \" يونس \" عليه السلام.
