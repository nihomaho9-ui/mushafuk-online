تيسير الكريم الرحمن — السعدي

وَمِن قَبْلِهِۦ كِتَـٰبُ مُوسَىٰٓ إِمَامًا وَرَحْمَةً ۚ وَهَـٰذَا كِتَـٰبٌ مُّصَدِّقٌ لِّسَانًا عَرَبِيًّا لِّيُنذِرَ ٱلَّذِينَ ظَلَمُوا۟ وَبُشْرَىٰ لِلْمُحْسِنِينَ ﴿١٢﴾

الذي قد وافق الكتب السماوية خصوصا أكملها وأفضلها بعد القرآن وهي التوراة التي أنزلها الله على موسى { إِمَامًا وَرَحْمَةً } أي: يقتدي بها بنو إسرائيل ويهتدون بها فيحصل لهم خير الدنيا والآخرة. { وَهَذَا } القرآن { كِتَابٌ مُصَدِّقٌ } للكتب السابقة شهد بصدقها وصدَّقها بموافقته لها وجعله الله { لِسَانًا عَرَبِيًّا } ليسهل تناوله ويتيسر تذكره، { لِيُنْذِرَ الَّذِينَ ظَلَمُوا } أنفسهم بالكفر والفسوق والعصيان إن استمروا على ظلمهم بالعذاب الوبيل ويبشر المحسنين في عبادة الخالق وفي نفع المخلوقين بالثواب الجزيل في الدنيا والآخرة ويذكر الأعمال التي ينذر عنها والأعمال التي يبشر بها.
