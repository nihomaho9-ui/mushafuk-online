تيسير الكريم الرحمن — السعدي

تُدَمِّرُ كُلَّ شَىْءٍۭ بِأَمْرِ رَبِّهَا فَأَصْبَحُوا۟ لَا يُرَىٰٓ إِلَّا مَسَـٰكِنُهُمْ ۚ كَذَٰلِكَ نَجْزِى ٱلْقَوْمَ ٱلْمُجْرِمِينَ ﴿٢٥﴾

{ تُدَمِّرُ كُلَّ شَيْءٍ } تمر عليه من شدتها ونحسها.فسلطها الله عليهم { سبع ليالي وثمانية أيام حسوما فترى القوم فيها صرعى كأنهم أعجاز نخل خاوية } [ { بِأَمْرِ رَبِّهَا } أي: بإذنه ومشيئته]. { فَأَصْبَحُوا لَا يُرَى إِلَّا مَسَاكِنُهُمْ } قد تلفت مواشيهم وأموالهم وأنفسهم. { كَذَلِكَ نَجْزِي الْقَوْمَ الْمُجْرِمِينَ } بسبب جرمهم وظلمهم.
