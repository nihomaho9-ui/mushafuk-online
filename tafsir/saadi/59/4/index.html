الحشرالآية ٤

تيسير الكريم الرحمن — السعدي

ذَٰلِكَ بِأَنَّهُمْ شَآقُّوا۟ ٱللَّهَ وَرَسُولَهُۥ ۖ وَمَن يُشَآقِّ ٱللَّهَ فَإِنَّ ٱللَّهَ شَدِيدُ ٱلْعِقَابِ ﴿٤﴾

وذلك لأنهم { شَاقُّوا اللَّهَ وَرَسُولَهُ } وعادوهما وحاربوهما، وسعوا في معصيتهما.وهذه عادته وسنته فيمن شاقه { وَمَنْ يُشَاقِّ اللَّهَ فَإِنَّ اللَّهَ شَدِيدُ الْعِقَابِ }
