سبأالآية ٤٩

تيسير الكريم الرحمن — السعدي

قُلْ جَآءَ ٱلْحَقُّ وَمَا يُبْدِئُ ٱلْبَـٰطِلُ وَمَا يُعِيدُ ﴿٤٩﴾

فيعلم بها عباده, ويبينها لهم, ولهذا قال: { قُلْ جَاءَ الْحَقُّ } أي: ظهر وبان, وصار بمنزلة الشمس, وظهر سلطانه، { وَمَا يُبْدِئُ الْبَاطِلُ وَمَا يُعِيدُ } أي: اضمحل وبطل أمره, وذهب سلطانه, فلا يبدئ ولا يعيد.
