سبأالآية ٥٤

تيسير الكريم الرحمن — السعدي

وَحِيلَ بَيْنَهُمْ وَبَيْنَ مَا يَشْتَهُونَ كَمَا فُعِلَ بِأَشْيَاعِهِم مِّن قَبْلُ ۚ إِنَّهُمْ كَانُوا۟ فِى شَكٍّ مُّرِيبٍۭ ﴿٥٤﴾

{ وَحِيلَ بَيْنَهُمْ وَبَيْنَ مَا يَشْتَهُونَ } من الشهوات واللذات, والأولاد, والأموال, والخدم, والجنود، قد انفردوا بأعمالهم, وجاءوا فرادى, كما خلقوا, وتركوا ما خولوا, وراء ظهورهم، { كَمَا فُعِلَ بِأَشْيَاعِهِمْ } من الأمم السابقين, حين جاءهم الهلاك, حيل بينهم وبين ما يشتهون، { إِنَّهُمْ كَانُوا فِي شَكٍّ مُرِيبٍ } أي: محدث الريبة وقلق القلب فلذلك, لم يؤمنوا, ولم يعتبوا حين استعتبوا.تم تفسير سورة سبأ - وللّه الحمد والمنة, والفضل, ومنه العون, وعليه التوكل, وبه الثقة.
