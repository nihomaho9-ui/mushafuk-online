سبأالآية ٥

تيسير الكريم الرحمن — السعدي

وَٱلَّذِينَ سَعَوْ فِىٓ ءَايَـٰتِنَا مُعَـٰجِزِينَ أُو۟لَـٰٓئِكَ لَهُمْ عَذَابٌ مِّن رِّجْزٍ أَلِيمٌ ﴿٥﴾

{ وَالَّذِينَ سَعَوْا فِي آيَاتِنَا مُعَاجِزِينَ } أي: سعوا فيها كفرا بها, وتعجيزا لمن جاء بها, وتعجيزا لمن أنزلها, كما عجزوه في الإعادة بعد الموت. { أُولَئِكَ لَهُمْ عَذَابٌ مِنْ رِجْزٍ أَلِيمٌ } أي: مؤلم لأبدانهم وقلوبهم.
