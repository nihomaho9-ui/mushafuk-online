تيسير الكريم الرحمن — السعدي

وَمِنْ ءَابَآئِهِمْ وَذُرِّيَّـٰتِهِمْ وَإِخْوَٰنِهِمْ ۖ وَٱجْتَبَيْنَـٰهُمْ وَهَدَيْنَـٰهُمْ إِلَىٰ صِرَٰطٍ مُّسْتَقِيمٍ ﴿٨٧﴾

{ وَمِنْ آبَائِهِمْ } أي: آباء هؤلاء المذكورين { وَذُرِّيَّاتِهِمْ وَإِخْوَانِهِمْ } أي: وهدينا من آباء هؤلاء وذرياتهم وإخوانهم. { وَاجْتَبَيْنَاهُمْ } أي: اخترناهم { وَهَدَيْنَاهُمْ إِلَى صِرَاطٍ مُسْتَقِيمٍ }
