تيسير الكريم الرحمن — السعدي

كَذَٰلِكَ وَزَوَّجْنَـٰهُم بِحُورٍ عِينٍ ﴿٥٤﴾

{ كَذَلِكَ } النعيم التام والسرور الكامل { وَزَوَّجْنَاهُمْ بِحُورٍ عين } أي: نساء جميلات من جمالهن وحسنهن أنه يحار الطرف في حسنهن وينبهر العقل بجمالهن وينخلب اللب لكمالهن { عَيْنٍ } أي: ضخام الأعين حسانها.
