يونسالآية ٨٤

تيسير الكريم الرحمن — السعدي

وَقَالَ مُوسَىٰ يَـٰقَوْمِ إِن كُنتُمْ ءَامَنتُم بِٱللَّهِ فَعَلَيْهِ تَوَكَّلُوٓا۟ إِن كُنتُم مُّسْلِمِينَ ﴿٨٤﴾

{ وَقَالَ مُوسَى } موصيًا لقومه بالصبر، ومذكرًا لهم ما يستعينون به على ذلك فقال: { يَا قَوْمِ إِنْ كُنْتُمْ آمَنْتُمْ بِاللَّهِ } فقوموا بوظيفة الإيمان. { فَعَلَيْهِ تَوَكَّلُوا إِنْ كُنْتُمْ مُسْلِمِينَ } أي: اعتمدوا عليه، والجؤوا إليه واستنصروه.
