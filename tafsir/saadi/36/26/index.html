يسالآية ٢٦

تيسير الكريم الرحمن — السعدي

قِيلَ ٱدْخُلِ ٱلْجَنَّةَ ۖ قَالَ يَـٰلَيْتَ قَوْمِى يَعْلَمُونَ ﴿٢٦﴾

فـ { قِيلَ } له في الحال: { ادْخُلِ الْجَنَّةَ } فقال مخبرا بما وصل إليه من الكرامة على توحيده وإخلاصه، وناصحا لقومه بعد وفاته، كما نصح لهم في حياته: { يَا لَيْتَ قَوْمِي يَعْلَمُونَ بِمَا غَفَرَ لِي رَبِّي }
