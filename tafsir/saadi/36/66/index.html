تيسير الكريم الرحمن — السعدي

وَلَوْ نَشَآءُ لَطَمَسْنَا عَلَىٰٓ أَعْيُنِهِمْ فَٱسْتَبَقُوا۟ ٱلصِّرَٰطَ فَأَنَّىٰ يُبْصِرُونَ ﴿٦٦﴾

{ وَلَوْ نَشَاءُ لَطَمَسْنَا عَلَى أَعْيُنِهِمْ } بأن نُذْهِبَ أبصارهم، كما طمسنا على نطقهم. { فَاسْتَبَقُوا الصِّرَاطَ } أي: فبادروا إليه، لأنه الطريق إلى الوصول إلى الجنة، { فَأَنَّى يُبْصِرُونَ } وقد طمست أبصارهم.
