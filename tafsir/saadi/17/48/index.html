الإسراءالآية ٤٨

تيسير الكريم الرحمن — السعدي

ٱنظُرْ كَيْفَ ضَرَبُوا۟ لَكَ ٱلْأَمْثَالَ فَضَلُّوا۟ فَلَا يَسْتَطِيعُونَ سَبِيلًا ﴿٤٨﴾

قال تعالى: { انْظُرْ } متعجبا { كَيْفَ ضَرَبُوا لَكَ الْأَمْثَالَ } التي هي أضل الأمثال وأبعدها عن الصواب { فَضَلُّوا } في ذلك أو فصارت سببا لضلالهم لأنهم بنوا عليها أمرهم والمبني على فاسد أفسد منه. { فَلَا يَسْتَطِيعُونَ سَبِيلًا } أي: لا يهتدون أي اهتداء فنصيبهم الضلال المحض والظلم الصرف.
