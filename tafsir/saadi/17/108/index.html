تيسير الكريم الرحمن — السعدي

وَيَقُولُونَ سُبْحَـٰنَ رَبِّنَآ إِن كَانَ وَعْدُ رَبِّنَا لَمَفْعُولًا ﴿١٠٨﴾

{ وَيَقُولُونَ سُبْحَانَ رَبِّنَا } عما لا يليق بجلاله، مما نسبه إليه المشركون. { إِنْ كَانَ وَعْدُ رَبِّنَا } بالبعث والجزاء بالأعمال { لَمَفْعُولًا } لا خلف فيه ولا شك.
