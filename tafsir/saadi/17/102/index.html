تيسير الكريم الرحمن — السعدي

قَالَ لَقَدْ عَلِمْتَ مَآ أَنزَلَ هَـٰٓؤُلَآءِ إِلَّا رَبُّ ٱلسَّمَـٰوَٰتِ وَٱلْأَرْضِ بَصَآئِرَ وَإِنِّى لَأَظُنُّكَ يَـٰفِرْعَوْنُ مَثْبُورًا ﴿١٠٢﴾

فـ { قَالَ } له موسى { لَقَدْ عَلِمْتَ } يا فرعون { مَا أَنْزَلَ هَؤُلَاءِ } الآيات { إِلَّا رَبُّ السَّمَاوَاتِ وَالْأَرْضِ بَصَائِرَ } منه لعباده، فليس قولك هذا بالحقيقة، وإنما قلت ذلك ترويجًا على قومك، واستخفافًا لهم. { وَإِنِّي لَأَظُنُّكَ يَا فِرْعَوْنُ مَثْبُورًا } أي: ممقوتًا، ملقى في العذاب، لك الويل والذم واللعنة.
