تيسير الكريم الرحمن — السعدي

ٱللَّهُ ٱلَّذِى يُرْسِلُ ٱلرِّيَـٰحَ فَتُثِيرُ سَحَابًا فَيَبْسُطُهُۥ فِى ٱلسَّمَآءِ كَيْفَ يَشَآءُ وَيَجْعَلُهُۥ كِسَفًا فَتَرَى ٱلْوَدْقَ يَخْرُجُ مِنْ خِلَـٰلِهِۦ ۖ فَإِذَآ أَصَابَ بِهِۦ مَن يَشَآءُ مِنْ عِبَادِهِۦٓ إِذَا هُمْ يَسْتَبْشِرُونَ ﴿٤٨﴾

يخبر تعالى عن كمال قدرته وتمام نعمته أنه { يُرْسِلُ الرِّيَاحَ فَتُثِيرُ سَحَابًا } من الأرض، { فَيَبْسُطُهُ فِي السَّمَاءِ } أي: يمده ويوسعه { كَيْفَ يَشَاءُ } أي: على أي حالة أرادها من ذلك ثم { يَجْعَلُهُ } أي: ذلك السحاب الواسع { كِسَفًا } أي: سحابا ثخينا قد طبق بعضه فوق بعض.{ فَتَرَى الْوَدْقَ يَخْرُجُ مِنْ خِلَالِهِ } أي: السحاب نقطا صغارا متفرقة، لا تنزل جميعا فتفسد ما أتت عليه.{ فَإِذَا أَصَابَ بِهِ } بذلك المطر { مَنْ يَشَاءُ مِنْ عِبَادِهِ إِذَا هُمْ يَسْتَبْشِرُونَ } يبشر بعضهم بعضا بنزوله وذلك لشدة حاجتهم وضرورتهم إليه .
