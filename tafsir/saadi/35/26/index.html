فاطرالآية ٢٦

تيسير الكريم الرحمن — السعدي

ثُمَّ أَخَذْتُ ٱلَّذِينَ كَفَرُوا۟ ۖ فَكَيْفَ كَانَ نَكِيرِ ﴿٢٦﴾

{ ثُمَّ أَخَذْتُ الَّذِينَ كَفَرُوا } بأنواع العقوبات { فَكَيْفَ كَانَ نَكِيرِ } عليهم؟ كان أشد النكير وأعظم التنكيل، فإياكم وتكذيب هذا الرسول الكريم، فيصيبكم كما أصاب أولئك، من العذاب الأليم والخزي الوخيم.
