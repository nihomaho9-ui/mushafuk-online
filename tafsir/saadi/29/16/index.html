العنكبوتالآية ١٦

تيسير الكريم الرحمن — السعدي

وَإِبْرَٰهِيمَ إِذْ قَالَ لِقَوْمِهِ ٱعْبُدُوا۟ ٱللَّهَ وَٱتَّقُوهُ ۖ ذَٰلِكُمْ خَيْرٌ لَّكُمْ إِن كُنتُمْ تَعْلَمُونَ ﴿١٦﴾

يذكر تعالى أنه أرسل خليله إبراهيم عليه الصلاة والسلام إلى قومه، يدعوهم إلى الله، فقال [لهم]: { اعْبُدُوا اللَّهَ } أي: وحِّدوه، وأخلصوا له العبادة، وامتثلوا ما أمركم به، { وَاتَّقُوهُ } أن يغضب عليكم، فيعذبكم، وذلك بترك ما يغضبه من المعاصي، { ذَلِكُمْ } أي: عبادة الله وتقواه { خَيْرٌ لَكُمْ } من ترك ذلك، وهذا من باب إطلاق { أفعل التفضيل } بما ليس في الطرف الآخر منه شيء، فإن ترك عبادة الله، وترك تقواه، لا خير فيه بوجه، وإنما كانت عبادة الله وتقواه خيرا للناس، لأنه لا سبيل إلى نيل كرامته في الدنيا والآخرة إلا بذلك، وكل خير يوجد في الدنيا والآخرة، فإنه من آثار عبادة الله وتقواه.{ إِنْ كُنْتُمْ تَعْلَمُونَ } ذلك، فاعلموا الأمور وانظروا ما هو أولى بالإيثار.
