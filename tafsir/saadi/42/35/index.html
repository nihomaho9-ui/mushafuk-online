تيسير الكريم الرحمن — السعدي

وَيَعْلَمَ ٱلَّذِينَ يُجَـٰدِلُونَ فِىٓ ءَايَـٰتِنَا مَا لَهُم مِّن مَّحِيصٍ ﴿٣٥﴾

ثم قال تعالى: { وَيَعْلَمَ الَّذِينَ يُجَادِلُونَ فِي آيَاتِنَا } ليبطلوها بباطلهم. { مَا لَهُمْ مِنْ مَحِيصٍ } أي: لا ينقذهم منقذ مما حل بهم من العقوبة.
