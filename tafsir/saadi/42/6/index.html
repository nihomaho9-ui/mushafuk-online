تيسير الكريم الرحمن — السعدي

وَٱلَّذِينَ ٱتَّخَذُوا۟ مِن دُونِهِۦٓ أَوْلِيَآءَ ٱللَّهُ حَفِيظٌ عَلَيْهِمْ وَمَآ أَنتَ عَلَيْهِم بِوَكِيلٍ ﴿٦﴾

{ وَالَّذِينَ اتَّخَذُوا مِنْ دُونِهِ أَوْلِيَاءَ } يتولونهم بالعبادة والطاعة، كما يعبدون الله ويطيعونه، فإنما اتخذوا الباطل، وليسوا بأولياء على الحقيقة. { اللَّهُ حَفِيظٌ عَلَيْهِمْ } يحفظ عليهم أعمالهم، فيجازيهم بخيرها وشرها. { وَمَا أَنْتَ عَلَيْهِمْ بِوَكِيلٍ } فتسأل عن أعمالهم، وإنما أنت مبلغ أديت وظيفتك.
