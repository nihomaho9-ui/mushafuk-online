الفجرالآية ٢٣

تيسير الكريم الرحمن — السعدي

وَجِا۟ىٓءَ يَوْمَئِذٍۭ بِجَهَنَّمَ ۚ يَوْمَئِذٍ يَتَذَكَّرُ ٱلْإِنسَـٰنُ وَأَنَّىٰ لَهُ ٱلذِّكْرَىٰ ﴿٢٣﴾

{ وَجِيءَ يَوْمَئِذٍ بِجَهَنَّمَ } تقودها الملائكة بالسلاسل.فإذا وقعت هذه الأمور فـ { يَوْمَئِذٍ يَتَذَكَّرُ الْإِنْسَانُ } ما قدمه من خير وشر.{ وَأَنَّى لَهُ الذِّكْرَى } فقد فات أوانها، وذهب زمانها.
