الحجالآية ٥٠

تيسير الكريم الرحمن — السعدي

فَٱلَّذِينَ ءَامَنُوا۟ وَعَمِلُوا۟ ٱلصَّـٰلِحَـٰتِ لَهُم مَّغْفِرَةٌ وَرِزْقٌ كَرِيمٌ ﴿٥٠﴾

ثم ذكر تفصيل النذارة والبشارة فقال: { فَالَّذِينَ آمَنُوا } بقلوبهم إيمانا صحيحا صادقا { وَعَمِلُوا الصَّالِحَاتِ } بجوارحهم { في جنات النعيم } أي: الجنات التي يتنعم بها بأنواع النعيم من المآكل والمشارب والمناكح والصور والأصوات والتنعم برؤية الرب الكريم وسماع كلامه .
