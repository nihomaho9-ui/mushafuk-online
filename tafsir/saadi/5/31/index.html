تيسير الكريم الرحمن — السعدي

فَبَعَثَ ٱللَّهُ غُرَابًا يَبْحَثُ فِى ٱلْأَرْضِ لِيُرِيَهُۥ كَيْفَ يُوَٰرِى سَوْءَةَ أَخِيهِ ۚ قَالَ يَـٰوَيْلَتَىٰٓ أَعَجَزْتُ أَنْ أَكُونَ مِثْلَ هَـٰذَا ٱلْغُرَابِ فَأُوَٰرِىَ سَوْءَةَ أَخِى ۖ فَأَصْبَحَ مِنَ ٱلنَّـٰدِمِينَ ﴿٣١﴾

فلما قتل أخاه لم يدر كيف يصنع به؛ لأنه أول ميت مات من بني آدم { فَبَعَثَ اللَّهُ غُرَابًا يَبْحَثُ فِي الْأَرْضِ } أي: يثيرها ليدفن غرابا آخر ميتا. { لِيُرِيَهُ } بذلك { كَيْفَ يُوَارِي سَوْأَةَ أَخِيهِ } أي: بدنه، لأن بدن الميت يكون عورة { فَأَصْبَحَ مِنَ النَّادِمِينَ } وهكذا عاقبة المعاصي الندامة والخسارة.
