تيسير الكريم الرحمن — السعدي

ذَٰلِكَ بِأَنَّهُمْ ءَامَنُوا۟ ثُمَّ كَفَرُوا۟ فَطُبِعَ عَلَىٰ قُلُوبِهِمْ فَهُمْ لَا يَفْقَهُونَ ﴿٣﴾

{ ذَلِكَ } الذي زين لهم النفاق { بـ } سبب أنهم لا يثبتون على الإيمان.بل { آمَنُوا ثُمَّ كَفَرُوا فَطُبِعَ عَلَى قُلُوبِهِمْ } بحيث لا يدخلها الخير أبدًا، { فَهُمْ لَا يَفْقَهُونَ } ما ينفعهم، ولا يعون ما يعود بمصالحهم.
