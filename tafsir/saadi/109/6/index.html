تيسير الكريم الرحمن — السعدي

لَكُمْ دِينُكُمْ وَلِىَ دِينِ ﴿٦﴾

ولهذا ميز بين الفريقين، وفصل بين الطائفتين، فقال: { لَكُمْ دِينُكُمْ وَلِيَ دِينِ } كما قال تعالى: { قُلْ كُلٌّ يَعْمَلُ عَلَى شَاكِلَتِهِ } { أَنْتُمْ بَرِيئُونَ مِمَّا أَعْمَلُ وَأَنَا بَرِيءٌ مِمَّا تَعْمَلُونَ } .
