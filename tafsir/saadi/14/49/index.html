تيسير الكريم الرحمن — السعدي

وَتَرَى ٱلْمُجْرِمِينَ يَوْمَئِذٍ مُّقَرَّنِينَ فِى ٱلْأَصْفَادِ ﴿٤٩﴾

{ وَتَرَى الْمُجْرِمِينَ } أي: الذين وصفهم الإجرام وكثرة الذنوب، { يَوْمَئِذٍ } في ذلك اليوم { مُقَرَّنِينَ فِي الْأَصْفَادِ } أي: يسلسل كل أهل عمل من المجرمين بسلاسل من نار فيقادون إلى العذاب في أذل صورة وأشنعها وأبشعها.
