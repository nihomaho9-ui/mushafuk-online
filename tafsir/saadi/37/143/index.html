تيسير الكريم الرحمن — السعدي

فَلَوْلَآ أَنَّهُۥ كَانَ مِنَ ٱلْمُسَبِّحِينَ ﴿١٤٣﴾

{ فَلَوْلَا أَنَّهُ كَانَ مِنَ الْمُسَبِّحِينَ } أي: في وقته السابق بكثرة عبادته لربه، وتسبيحه، وتحميده، وفي بطن الحوت حيث قال: { لَا إِلَهَ إِلَّا أَنْتَ سُبْحَانَكَ إِنِّي كُنْتُ مِنَ الظَّالِمِينَ }
