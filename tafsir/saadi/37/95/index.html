تيسير الكريم الرحمن — السعدي

قَالَ أَتَعْبُدُونَ مَا تَنْحِتُونَ ﴿٩٥﴾

الآيات ٩٥–٩٦{ قَالَ } هنا: { أَتَعْبُدُونَ مَا تَنْحِتُونَ } أي: تنحتونه بأيديكم وتصنعونه؟ فكيف تعبدونهم، وأنتم الذين صنعتموهم، وتتركون الإخلاص للّه؟ الذي { خَلَقَكُمْ وَمَا تَعْمَلُونَ}.
