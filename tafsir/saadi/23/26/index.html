تيسير الكريم الرحمن — السعدي

قَالَ رَبِّ ٱنصُرْنِى بِمَا كَذَّبُونِ ﴿٢٦﴾

فلما رأى نوح أنه لا يفيدهم دعاؤه إلا فرارا { قَالَ رَبِّ انْصُرْنِي بِمَا كَذَّبُونِ } فاستنصر ربه عليهم، غضبا لله، حيث ضيعوا أمره، وكذبوا رسوله وقال: { رَبِّ لَا تَذَرْ عَلَى الْأَرْضِ مِنَ الْكَافِرِينَ دَيَّارًا* إِنَّكَ إِنْ تَذَرْهُمْ يُضِلُّوا عِبَادَكَ وَلَا يَلِدُوا إِلَّا فَاجِرًا كَفَّارًا } قال تعالى: { وَلَقَدْ نَادَانَا نُوحٌ فَلَنِعْمَ الْمُجِيبُونَ }
