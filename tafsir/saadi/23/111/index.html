تيسير الكريم الرحمن — السعدي

إِنِّى جَزَيْتُهُمُ ٱلْيَوْمَ بِمَا صَبَرُوٓا۟ أَنَّهُمْ هُمُ ٱلْفَآئِزُونَ ﴿١١١﴾

{ إِنِّي جَزَيْتُهُمُ الْيَوْمَ بِمَا صَبَرُوا } على طاعتي، وعلى أذاكم، حتى وصلوا إلي. { أَنَّهُمْ هُمُ الْفَائِزُونَ } بالنعيم المقيم، والنجاة من الجحيم، كما قال في الآية الأخرى: { فَالْيَوْمَ الَّذِينَ آمَنُوا مِنَ الْكُفَّارِ يَضْحَكُونَ } الآيات.
