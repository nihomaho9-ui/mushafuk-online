تيسير الكريم الرحمن — السعدي

قُلْ مَن رَّبُّ ٱلسَّمَـٰوَٰتِ ٱلسَّبْعِ وَرَبُّ ٱلْعَرْشِ ٱلْعَظِيمِ ﴿٨٦﴾

{ قُلْ مَنْ رَبُّ السَّمَاوَاتِ السَّبْعِ } وما فيها من النيرات، والكواكب السيارات، والثوابت { وَرَبُّ الْعَرْشِ الْعَظِيمِ } الذي هو أعلى المخلوقات وأوسعها وأعظمها، فمن الذي خلق ذلك ودبره، وصرفه بأنواع التدبير؟
