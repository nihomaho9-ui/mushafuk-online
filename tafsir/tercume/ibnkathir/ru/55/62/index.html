Аят 62

Тафсир Ибн Касир

وَمِن دُونِهِمَا جَنَّتَانِ ﴿٦٢﴾

Кроме двух садов, о которых говорилось выше, есть еще два сада. Они более значимые, чем предыдущие. Аллах сказал: ﴾وَمِندُونِهِمَاجَنَّتَانِ﴿ «А перед теми двумя есть еще два сада». Уже приводился хадис, в котором сообщалось: « جنتانمنذهب؛آنيتهماومافيهما،وجنتانمنفضة؛آنيتهماومافيهما » «Два сада, сосуды и все прочее в которых(сделано) из золота, и два сада, сосуды и все прочее в которых(сделано) из серебра». Первые два сада уготованы для приближенных к Аллаху, а два других — для людей правой стороны. Абу Муса сказал: «Два золотых сада — для приближенных, а два серебряных — для тех, кто окажется по правую сторону». Из этого следует, что первые два сада превосходят два вторых.
