Аят 56

Тафсир Ибн Касир

وَمَا خَلَقْتُ ٱلْجِنَّ وَٱلْإِنسَ إِلَّا لِيَعْبُدُونِ ﴿٥٦﴾

Затем Аллах Всевышний говорит: { وَمَا خَلَقْتُ ٱلْجِنّ وَٱلإِنسَ إِلَّا لِيـَعْبُدُونِ } «Я сотворил джиннов и людей только для того, чтобы они поклонялись Мне» — т.е. Я сотворил их для того, чтобы приказать им поклоняться Мне, а не потому, что у Меня есть в них нужда. Ибн ‘Аббас сказал: { إِلَّا لِيـَعْبُدُونِ } «‘‘Только для того, чтобы они поклонялись Мне’’ — т.е. добровольно или против своей воли». Также считал Ибн Джарир.
