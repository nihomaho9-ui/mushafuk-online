القيامةАят 11

Тафсир Ибн Касир

كَلَّا لَا وَزَرَ ﴿١١﴾

Аллах сказал:( كَلاَّ لاَ وَزَرَ * إِلَىٰ رَبِّكَ يَوْمَئِذٍ ٱلْمُسْتَقَرُّ ) «О нет! Не будет убежища! В тот день возвращение будет к твоему Господу». Ибн Мас'уд и Ибн 'Аббас сказали: «Не будет спасения».Подобно этому Аллах сказал:( مَا لَكُمْ مِّن مَّلْجَأٍ يَوْمَئِذٍ وَمَا لَكُمْ مِّن نَّكِيرٍ ) «В тот день не будет для вас убежища, и вы не сможете отрицать свои грехи»(42:47). – т.е. некуда будет спрятаться. Как и сказано здесь:( لاَ وَزَرَ ) «Не будет убежища!», т.е. негде будет укрыться.
