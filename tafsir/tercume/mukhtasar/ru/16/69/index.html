Аят 69

Тафсир аль-Мухтасар

ثُمَّ كُلِى مِن كُلِّ ٱلثَّمَرَٰتِ فَٱسْلُكِى سُبُلَ رَبِّكِ ذُلُلًا ۚ يَخْرُجُ مِنۢ بُطُونِهَا شَرَابٌ مُّخْتَلِفٌ أَلْوَٰنُهُۥ فِيهِ شِفَآءٌ لِّلنَّاسِ ۗ إِنَّ فِى ذَٰلِكَ لَـَٔايَةً لِّقَوْمٍ يَتَفَكَّرُونَ ﴿٦٩﴾

Затем, питайся всеми плодами, какие пожелаешь, и следуй по доступным путям, по которым твой Господь внушил тебе следовать». Из брюшков этих пчел исходит мед разных цветов: белого, желтого и другого [цвета], и им люди исцеляют свои болезни. Поистине, во внушении пчеле этого и в меде, который исходит из их брюшков, есть доказательство могущества Аллаха и Его управления делами Своих творений для людей размышляющих, ибо только такие могут извлекать из этого урок.
